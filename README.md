# Assets_Farm — шаблон Unity для новых паков

Создавайте ветку нового пака от `master`. Модели, сцены, каталоги и материалы Asset Store храните в ветке этого пака.

## Что есть в шаблоне

- [REQUIREMENTS.md](REQUIREMENTS.md) — требования к моделям, сценам, поставке и оформлению страницы Asset Store.
- [PLAN.md](PLAN.md) — реестр продуктов и порядок производства от выбора темы до публикации.
- [Tools/README.md](Tools/README.md) — конвейер Blender и Unity, шаблон скрипта для реестра моделей и шаблоны ревью.
- [PackTools](Assets/Editor/PackTools) — редакторские инструменты для импорта моделей, сборки префабов и сцен.
- `Assets/Settings`, `Packages` и `ProjectSettings` — настройки Unity 6000.3.10f1 и URP. Список сцен сборки пуст.
- `.claude/` — инструкции и шаблон рендера превью для производства моделей.

## Как начать новый пак

1. Создайте ветку от `master` и определите тему, состав и ограничения пака по [плану](PLAN.md#6-основной-процесс-производства-каждого-пака).
2. Составьте каталог и проверьте 2–3 пилотные модели по [требованиям к конвейеру](REQUIREMENTS.md#10-производственный-конвейер-моделей).
3. Для импорта задайте `PackConfig` своего пака. Пример обвязки есть в `Assets/Editor/FarmProcessing/` в ветке `Farm-Processing`. После подготовки демо добавьте его в список сцен сборки.
