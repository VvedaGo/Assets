# VFX — шаблон и общие правила линейки

Ветка `master` служит исходным Unity-проектом для новых паков и хранит общие требования. Модели, сцены конкретных продуктов, промо-изображения и архивы загрузки размещаются в рабочих ветках продуктов.

## Что оставлено

- `Assets/Settings` — общие настройки URP.
- `Assets/InputSystem_Actions.inputactions` и соответствующие `.meta`.
- `Packages` и `ProjectSettings` — существующая конфигурация проекта Unity 6000.3.10f1 / URP 17.3.0.
- `REQUIREMENTS.md` — общий стандарт производства и оформления.
- `PLAN.md` — реестр продуктов и план линейки.

В Build Settings нет сцен конкретного пака. Перед сборкой нового продукта добавить его собственную демо-сцену. Состав пакетов Unity сохранён; эта уборка не пересматривает общие зависимости.
