# Farm Nature — композиции сцены

Созданы по объектным референсам из `NATURE_REFERENCES`. Концепты для сборки, не скриншоты Unity. Генерация может упрощать отдельные формы; точный состав объектов брать из исходного каталога.

- `01_Overall_Composition.png` — связная сцена: огород впереди слева, поля позади него, сад в середине, лес на заднем плане, пруд справа. Тропа ведёт от переднего края к развилке и мосту.
- `02_Showcase_Layout.png` — выставочная сцена: шесть островов с категориями, индивидуальными номерами и сравнением стадий роста слева направо.
- `03_Local_Compositions.png` — шесть самостоятельных групп: огород, поле, яблоневый сад, пруд с мостом, опушка, цветочная тропа.

## Общие правила сборки и плашек

Гранёная геометрия, матовые материалы, зелёная листва, золотые поля, тёплое дерево и коричневая земля. Свет сверху слева, камера ортографическая с наклоном около 40–45 градусов. Высокие растения и деревья сзади, мелкие детали впереди; оставлять промежутки для чтения силуэтов.

Плашки: тёмно-зелёный фон и кремовые надписи. Для итогового набора использовать простой скруглённый прямоугольник и один шрифт без засечек, как на листах 01–02; декоративную форму и шрифт листа 03 не переносить. Заголовок сверху, названия локальных композиций снизу. В выставочной сцене табличка категории стоит сзади слева, номера — на переднем крае у объектов; стадии роста обозначаются 1 / 2 / 3. Выноски общей сцены размещать за её границей, не поверх растений.

Планируемый проход между выставочными островами — около 2 м, свободный край вокруг экспонатов — около 0,5 м; окончательные расстояния подбирать после проверки реального масштаба моделей. В связной сцене мост соединяет оба берега, тропа подходит к обоим концам. Растения размещать асимметричными группами, не закрывая входы на тропы.
