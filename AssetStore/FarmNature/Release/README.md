# Farm Nature 1.0.0 — подготовленная поставка

Файл для Asset Store Tools: **FarmNature_1.0.0.unitypackage**. Размер: **9 031 526 байт / 8.61 MiB**. Цена карточки: **9.99 USD**. Поддержка: **sergvved@gmail.com**.

## Что находится в проекте

Готовый исходный пакет — `Assets/FarmNature`. Внутри только Art, Demo, Documentation, редакторское окно Getting Started и стартовая инструкция. Все модели, материалы, текстуры и префабы сохранены с GUID. Посторонние паки проекта не удалены и не включены в экспорт.

Открыть **Tools > Farm Nature > Getting Started > Open Showcase Scene**. В сцене понятные группы Overview / Scene Studies / Asset Collection / Presentation, одна активная камера и Audio Listener. Шесть локальных сцен-примеров сохранены. Внутренние камеры для маркетинговых рендеров и иконная виньетка исключены из релизной сцены. Исходная производственная версия сохранена вне Assets в `output/FarmNature_1.0.0_Preparation/SourceBackup`.

Документация, Changelog 1.0.0, модельный реестр и необязательная демо-конфигурация URP входят в пакет. Демо-настройки не изменяют Graphics/Quality пользователя автоматически. Производственные генераторы, референсы, маркетинговые изображения, node_modules, логи, аккаунтные данные и остальные Assets в .unitypackage не входят.

## Подтверждённые проверки

- Сборка и отдельный чистый импорт в Unity 6000.3.10f1 / URP 17.3.0.
- 88 арт-префабов: ссылки на Mesh и материалы, корневые transforms, наличие одного коллайдера.
- Unity Mesh.triangles: 60–6514 на модель, всего 118 908; совпадает с измерениями исходных FBX.
- Одна активная камера; отсутствуют missing scripts, отсутствующие меши, неподдерживаемые/ошибочные материалы по проверке.
- Зависимостей сцены или арт-префабов на другие Assets проекта нет.
- Просмотрен реальный рендер демо из чистого проекта — `CleanImport_Overview.png`.
- Asset Store Tools 12.0.6: **37 Pass, 0 Fail, 0 Warning** после исправления неба. Полный результат — `AssetStore_Validator.txt`.

Предупреждение `Check SRP Compatible Materials` устранено: M_Demo_Sky использует включённый URP-шейдер `FarmNature/Demo/URP Panorama Sky` из `Demo/Shaders/FarmNatureSky.shader`. Он сохраняет панорамную текстуру и проходит проверку SRP; вид сцены проверен повторным рендером после импорта. Остальные 34 материала используют URP/Lit. Правила валидатора не изменялись, проверка не отключалась.

## Контроль поставки

`package-paths.txt` перечисляет все пути экспорта: все 288 записей расположены в Assets/FarmNature. `SHA256.txt` содержит контрольную сумму .unitypackage. `Validation.txt`, `Unity_Prefab_Audit.csv` и `Scene_Dependencies.txt` содержат результаты проверок.

Подготовка не включает сборку игры для целевых платформ, тестирование игрового поведения коллайдеров, проверку платформенной производительности или отправку на модерацию. Коллайдеры остаются простыми Box Collider; ограничение описано покупателю.

Перед отправкой издателю осталось подтвердить происхождение моделей/текстур и права на используемое содержимое, а также заполнить AI description по фактически использованным инструментам. Эти сведения не выдумывались. Подробности — `../PUBLISHER_NOTES.md`.

Файлы страницы: `../PACKAGE_METADATA.md`, `../Copy_Fields`, `../FarmNature_Store_Texts.zip`. Медиа: `../Media/Upload` и `../Media/FarmNature_Upload_v2.zip`. Ничего не загружено и не опубликовано в Publisher Portal.
