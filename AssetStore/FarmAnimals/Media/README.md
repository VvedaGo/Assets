## Editable sources and exports

Editable contains fourteen self-contained layered SVGs. Each has embedded image layers and editable Impact/Arial text and graphics. Open the SVGs in Inkscape or another tool that supports layer groups. The 160 px icon and 420 px card derive from the corresponding SVG masters.

For a clean rebuild from the saved raster sources, run the command below from the project root with Python, Pillow, Node.js, and @resvg/resvg-js installed. Supply the package directory from the Farm Nature media build or another installation.

~~~powershell
python AssetStore/FarmAnimals/Media/Editable/build_media.py "<path-to-node_modules/@resvg/resvg-js>"
~~~

Editable/RenderStudio.cs.txt can be passed as C# source to Unity CLI eval with the project open. It renders an unsaved additive catalog scene through FarmAnimalsShots.RenderOpen with PP_Presentation and uses Assets/_Presentation/Settings/StoreWireframe.shader to draw the baked mesh triangle edges. Demo stills are from FarmAnimalsDemoBuilder.RenderOpenScene. Existing shot renders and videos are source material. Renders and Video remain separate from Final.

The [Unity image template](https://assetstore.unity.com/publishing/image-template) lists the 160 × 160 icon, 420 × 280 card and 1950 × 1300 cover sizes. Other sizes follow the project brief. Portal appearance after upload and package runtime behavior are outside this media review.
