# Э10 scene Demo_Catalog + catalogue shots + Card/Icon sources (Unity assembler, 2026-11-26)

Wrapper `Assets/Editor/CottageGardenDecor/CottageGardenDecorCatalogScene.cs` (menus Tools/Cottage Garden Decor/Build Catalog Scene,
Render Catalog Shots). PackSceneBuilder places the items (no `comp` lines, CMP prefabs only as instances, never re-saved); the
wrapper adds the floor, labels, LOD forcing, wireframe overlay, islands/clouds for sky shots, fits one camera per shot and renders
with the approved look (Volume `FMS_Garden_Look` v2, `CottageGardenDecorLook.Render` = HDR path, 4096 shadows, MSAA, 2x supersampling).
Layouts are generated by a packer (rows by category, large items at the back, equal gaps 0.4–0.9 m, category gaps 1.2–1.6 m, row gap
≥ 0.75 × height of the next row so the label strip under each row stays visible):
`planning/CottageGardenDecor/layouts/Demo_Catalog.txt` (shipped scene) and `Catalog_Shots.txt` (media; built, rendered, deleted).
All LOD groups forced to LOD0 in the shots (catalogue distance would otherwise pick LOD1), except the LOD1 gazebo in 09.

Catalogue background: floor plane + camera background, rendered **#E9E7EB / #EBE9EC** (target #E9E9EC), the same for all
catalogue shots; contact shadows kept. Camera ¾ from above (bearing 172–176°, 36–46° down, vFOV 24–26).
Every shot has `<File>_labels.json` next to the PNG: per item `id`, `prefab`, pixel `rect` [x, y, w, h] (top-left origin, projected
LOD0 meshes) and per-category union rects — for the Э12 labels. Renders are text-free.
