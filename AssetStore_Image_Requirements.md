# Изображения для публикации в Unity Asset Store

Формат файлов: PNG или JPG. Не использовать чужие логотипы, интерфейсы или материалы, на которые нет прав.

## Marketing images — обязательные

| Файл | Размер | Что должно быть изображено |
|---|---:|---|
| `01_Icon.png` | 160 x 160 px | Простой узнаваемый значок ассета: главный эффект или символ на контрастном фоне. Название можно не добавлять — на маленьком размере оно плохо читается. |
| `02_Card.png` | 420 x 280 px | Карточка ассета для каталога: наиболее эффектный VFX, короткое читаемое название ассета и чистый фон. Важные элементы — в центре кадра. |
| `03_Cover.png` | 1950 x 1300 px | Главный баннер страницы: несколько лучших VFX из набора, название ассета, единый стиль и достаточно свободного пространства, чтобы кадр не выглядел перегруженным. |

## Screenshots & videos — изображения страницы ассета

Рекомендуется подготовить 8 скриншотов. Ширина каждого — минимум 1200 px; рекомендуемый единый размер: **1920 x 1080 px** (16:9).

| Файл | Размер | Что должно быть изображено |
|---|---:|---|
| `04_Hero_Showcase.png` | 1920 x 1080 px | Самый красивый главный кадр: ключевой эффект в игровом окружении. |
| `05_Full_Collection.png` | 1920 x 1080 px | Несколько VFX из набора одновременно, чтобы сразу показать объём контента. |
| `06_Closeup_Effect.png` | 1920 x 1080 px | Крупный план одного сильного эффекта: детали, частицы, свечение, анимация. |
| `07_Variations.png` | 1920 x 1080 px | Вариации эффекта: разные цвета, формы, элементы или уровни мощности. |
| `08_Gameplay_Use.png` | 1920 x 1080 px | Практическое применение: VFX в сцене боя, способности, удара, окружения и т. п. |
| `09_Second_Environment.png` | 1920 x 1080 px | Те же или другие эффекты в другом освещении либо окружении — показывает универсальность. |
| `10_Features_Overview.png` | 1920 x 1080 px | Аккуратный коллаж с короткими подписями: основные типы VFX, входящие в пакет. |
| `11_Unity_Setup.png` | 1920 x 1080 px | Unity Editor: пример prefab/настроек материала или системы частиц. Интерфейс должен быть читаемым и показывать реальную настройку. |

## Порядок загрузки

1. Сначала `04_Hero_Showcase.png` — он будет первым и самым важным скриншотом.
2. Затем `05`–`09`, чтобы показать разнообразие.
3. В конце `10_Features_Overview.png` и `11_Unity_Setup.png`.
4. Marketing images загружаются отдельно в блок **Marketing images**: icon, card и cover.

## Быстрый контроль перед загрузкой

- Все скриншоты выглядят как одна серия: одинаковая цветокоррекция, шрифт и визуальный стиль.
- На изображениях нет водяных знаков и нечитаемого мелкого текста.
- Первый скриншот показывает лучший результат без необходимости читать описание.
- Название ассета на Card и Cover не перекрывает главный VFX.
